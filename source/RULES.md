# 《小有名气》试验规则 r01-planner-2026-11-16

这些数字都是可调的游戏试验规则，不是已经验证的平衡，不是真实平台算法，也不能保证现实中一定火。机器可读版本是 `src/sim/rules.ts`，连同牌面、阅读篇目和虚构事件一起导出为 `public/rule-config.json`。

五组试验不共用金钱或涨粉。每组都能重开、保留自己的记录，并至少打满 10 轮。种子相同、决定相同，则手牌、题目风向和风险掷值相同。提交前的修改不掷风险。提交只结算一次，重复提交会被挡住。技能只有 0 和 1，在重开或进入下一轮时才变。工具只增加看得见的信息，结算函数不读工具开关。最终要给玩家看的整数，在各自公式写明的那一次 `floor` 才取整。A、C 的涨粉明确用已经取整的曝光。E 的展示曝光单独取整，涨粉用未截断的中间曝光。概率、完成度和留存做夹取。没有倒计时，也没有付款。

## A 卡槽

槽位：开篇、核心、情绪、收束。提交必须放满开篇、核心、收束。牌上的槽位标签决定它能进哪。同一张实例只能放一次。

每天能量 6。抓牌消耗 1，提交消耗 1。丑闻和硬分析同时在场时，提交再加 1。能量不够时按「下一天」，能量回到 6，没有等待。

技能 1：抓 7 张（否则 6）；每张牌的基础曝光 b ×1.15；可以指定改正最多一张技术错误。校对不消除风险标签。没改掉的技术错误让该牌完成度 −0.5，最低 0。

组合只记一次，不同组合可以同时存在：

- 新品吐槽和玩梗在相邻槽：曝光 ×1.5
- 丑闻和硬分析同时在场：转化 ×2，能量 +1
- 软广和硬分析同时在场：收入 +20，转化 ×0.9

n 是已放牌里的风险标签数。`P = clamp(0.15 × max(0, n−1), 0, 0.45)`。因此 n=0 或 1 时 P=0，n=2 时 0.15，n=3 时 0.30，n=4 及以上 0.45。

提交时用种子和题目掷一次 u，不看牌的位置：

- u < P/2：节流，曝光 ×0.6
- P/2 ≤ u < P：争议，转化 ×0.5，收入 ×0.8
- 否则无事

曝光 = floor(各牌 b 之和 × 玩梗倍率 × 风向 × 节流)。风向按题目标签：热 1.2、平 1、冷 0.8。

基础转化 = 0.02 + 0.005 × 平均有效完成度，再乘深组合、软广组合和争议，上限 0.12。涨粉 = floor(曝光 × 转化)。收入 = floor((5 + 10×软广张数 + 20×软广组合) × 争议收入系数)。

## B 拼版

默认版心 3×4。对照用 3×3，可选 4×4。没有额外栏线。每种模块在托盘里各有自己的实例，不能复制。可以移动和收回。技能 1 允许转 90 度，转完重新检查碰撞，面积不变。

只认正交共享边。对角为 0。一对模块无论共享几条边都只记一对，每对最多一条规则。移动或收回后按当前版面重算，不累加历史加分。

分析模块若没有正交相邻的玩梗，留存 −0.10。有至少一块玩梗贴着，则取消这项惩罚，并 +0.20。两块玩梗贴同一篇分析仍然只算一次正向。一块玩梗可以同时帮两篇分析。全篇正向最多记 2。

广告和广告正交贴在一起：留存 −0.10，新粉 −3。全篇最多记 2 对。共享三条边仍然是一对。

Q = 100 × 占用格 / 总格。R = clamp(0.35 + 0.35×占用率 − 0.10×未缓解分析 + 0.20×正向次数 − 0.10×广告对, 0, 1)。Q 和 R 分开显示。每块广告收入 15。新粉 = floor(100 × R × 0.1) − 3×计入的广告对，可以为负；多轮合计的涨粉不低于 0 只作为展示下限，单轮允许为负。

热点由种子和轮次生成一格，与工具无关。工具只是把这一格标出来。用类型相符的模块盖住它，只把该模块的局部结构分翻倍。局部底分：分析 10、清单 8、玩梗 3、广告 0。局部分不乘进 R 和收入。

## C 曲线

x 是阅读进度 0 到 99，正好 100 个点，不是时钟。基础 `A = 60 − d×x`，`d = 0.60×(1 − 0.20×校对技能)`。阈值 25。正向倍率 `m = 1 + 0.25×制作技能`。

只在 `x ≥ t` 时加上：

- 挑衅开头仅当 t=0：`+30×m×exp(−x/12)`，另加下沉 `−0.12×x`（这截下沉不乘 m）
- 事实：`+16×m×exp(−(x−t)/35)`
- 反转：`+30×m×exp(−(x−t)/14)`
- 笑话：`+18×m×exp(−(x−t)/22)`

`x < t` 时增量为 0。最终 A 夹到 0..100。每种最多一块，总共最多三块。进度只能是 0、10、…、90，同一格一块。落版前可以移走。

R =（A ≥ 25 的点数）/ 100。界面写成模型估计。不用第一次流失当主指标。H = max(A)。分享分 = round(H)。曝光 = floor((100 + 2×H)×(0.4 + 0.6×R))。涨粉 = floor(曝光 × 0.05 × R)。没有额外随机命中。

技能 0 且没有块：R=0.59，H=60，最高点在进度 0。

工具打开时，虚线预飞调用和落版相同的 `simulate`。工具关闭时，落版之后才画实线。

## D 调音台

密度、情绪、商业三根滑杆，范围 0..100。草稿和确认值一开始都是 50。十个委托各自有三段不同的目标区间，中心不全是 50。

拨杆不消耗校准，也不产生反馈。分析消耗 1 次，把草稿抄进确认值，这时才给反馈。技能 0 每轮 3 次，技能 1（写作）4 次。用完不能再白拿反馈。至少分析过一次才能出版，出版用最后一次确认值，不用未分析的草稿。

单轴：在区间内记 100，否则 `clamp(100 − 2×到最近边界的距离, 0, 100)`。匹配均值 ≥90 为 S，≥75 为 A，≥60 为 B，否则 C。

以确认情绪 e、确认商业 b：

- 曝光 = floor(匹配均值 × (1 + e/100))
- 转化 = 0.06 × (1 − 0.5×b/100)
- 收入 = floor(5 + 20×b/100)
- 风险概率 = 0.3×e/100，按种子掷一次。命中则本篇转化 ×0.6

工具显示的区间比真实区间向两侧放宽 10；分析技能 1 时只放宽 5。真实区间不被工具改写。

## E 时机

每天同时显示三则虚构事件，分别处于发酵、高潮、退潮，热度 80、140、60。下一天只让退潮的那则退出，补进一则新的发酵；另外两则保留编号、证据标签和各立场拥挤，并各自推进一个阶段。每则连续在场三天。第 1 天用出生日前史摆出三个阶段：发酵是当天出生的，高潮是前一天出生的，退潮是前两天出生的。明天预告就是下一天新进入的那则发酵，和实际换上的是同一条。只有「下一天」推进天数，发稿不推进。游戏不在第 3 天结束。

每天 2 点行动。新闻和吐槽各 1 点，技术拆解 2 点，唱反调 1 点。

立场系数按阶段：

- 新闻 1.5 / 0.8 / 0.5
- 吐槽 1.3 / 1 / 0.6
- 技术拆解 0.7 / 1.4 / 1
- 唱反调 0.8 / 1.1 / 0.8

每则事件、每种立场有自己的拥挤 c，0 到 4。换日不把拥挤清零。发出后该组合拥挤 +1。进入下一天时，对新的一天里仍在场或新进入的每个组合按种子加 0 或 1 个模拟竞争者。两项都封顶 4。

展示曝光 = floor(该则所处阶段的热度 × 立场系数 / (1 + 0.25×c))。这个取整只用于展示。

每则事件预先写好技术证据和反调证据是否成立，两种情况都会出现。技术拆解：证据成立转化 0.10，否则 0.02。唱反调：成立 0.06，否则 0.02。其他立场 0.04。

高潮（热度 140）里的吐槽和唱反调，风险 0.30，其余情况 0.10。命中则风险系数 0.5。沟通技能 1 把这个系数改成 0.75，不是免疫。涨粉 = floor(未截断的曝光中间值 × 转化 × 风险系数)。不先把曝光取整再乘。

网感技能 1 能看见明天会新进入的一则提要，当天不能发它。工具只显示四种立场系数的比例，不改热度、事实和结算。
