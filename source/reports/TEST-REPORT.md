# 测试报告

配置版本：`r01-planner-2026-11-16`。日期：2026-11-16。没有公开部署。

这一轮只改了两处：E 的事件改为始终错峰处于发酵、高潮、退潮；E 的涨粉改为用未截断曝光。A、C 的先取整曝光再算涨粉保持原式。B 的单轮负粉、合计不低于 0 没有改。A 的保底可提交手牌没有改。

规则差异全文在 `DIFFERENCES.md`。这里不称「无差异」。

## 单元测试

```bash
npm test
```

Vitest 2.1.8。5 个文件、30 个测试，全部通过，退出码 0。日志 `reports/unit.log`。

- A：P 的 0 / 0.15 / 0.30 / 0.45 阶梯，n=3 的 u=0.10、0.20、0.40，挪牌不改 u，同一种子十篇重放，技能 0 抓 6 张、技能 1 抓 7 张。
- B：对角为 0，一条边和三条边都只记一对，两块玩梗只加一次，收回后厌烦回来，十轮可记完。
- C：技能 0、无块时 R=0.59、H=60 在进度 0。进度 70 不改写更早的点。预飞和落版是同一个函数。十轮可落版。
- D：拨杆不减校准。分析从 3 到 2。出版用确认值 80 而不是后来的 10。技能 1 为 4 次。十轮可出版。
- E 错峰：第 1 到第 5 天的出生日和阶段有逐日断言。发酵、高潮、退潮每天同时在场。次日只有退潮者退出。同一编号连续三天，证据标签不变。明天预告等于下一天新进入的发酵。拥挤换日不归零，加到 4 后不再增加。同一种子重放拥挤一致。
- E 精度：`settlePayoff(44.8, 0.06, 0.75)` 的展示曝光是 44，涨粉是 2。若先把曝光取整再乘，涨粉会是 1。真实对局里的涨粉等于 `floor(未截断曝光 × 转化 × 风险系数)`。
